# CodeRush frontend

Пользовательский интерфейс на React, TypeScript и Vite. Русский язык, адаптивная
вёрстка, светлая и тёмная темы, CSS-анимации с поддержкой `prefers-reduced-motion`.
Логотип — собственный SVG с угловыми скобками и зелёным слешем.

## Запуск через Docker Compose

Из каталога `src`, рядом с существующим `.env`:

```powershell
docker compose up -d --build
```

Открой **https://localhost:8443**. Порт меняется через `FRONTEND_PORT` в `.env`
(по умолчанию 8443). Все запросы `/api` проксируются Nginx в API по внутреннему
порту 8080. Браузер обращается к одному origin: отдельная настройка CORS не нужна.
Внешний API-порт из `API_PORT` остаётся доступен на loopback для инструментов.

При первом запуске контейнер создаёт **самоподписанный локальный сертификат**
для localhost/127.0.0.1/::1. Браузер предупредит, что сертификат не доверенный.
Решение о доверии этому локальному сертификату принимает пользователь.
Публичную часть можно получить для проверки и ручного добавления в доверенные:

```powershell
docker compose cp frontend:/etc/nginx/certs/localhost.crt ./localhost.crt
```

Приватный ключ остаётся в volume `frontend_certs`. Не добавляй его в репозиторий.
Для внешнего развёртывания нужен сертификат доверенного центра и соответствующие
`server_name`/публикация портов. Текущая конфигурация предназначена для локальной работы.
Сертификат проверяется при старте и перевыпускается, если до истечения осталось меньше суток.

## Что работает

- Регистрация, вход, «запомнить меня», профиль и выход.
- Создание тренировки с выбором сложности, количества задач и времени.
- Кнопка «Начать тренировку»: создание, назначение случайных задач и переход в редактор.
- Возврат в тренировку из серверной истории, номер текущей задачи и серверный таймер.
- Пропуск, переход к следующей задаче, досрочное завершение и таблица результатов.
- Редактор CodeMirror 6: подсветка, автодополнение, сворачивание, номера строк,
  скобки, отмена изменений, поиск. Tab позволяет покинуть редактор с клавиатуры.
- Выбор всех 27 включённых сред из миграции backend (6 семейств языков).
  В тренировке показываются разрешённые задачей языки и её собственные шаблоны.
- Отправка кода с точным сохранением пробелов и перевода строк, стандартным
  вводом и ID назначенной задачи (`MatchProblem`, не `Problem` или `Match`).
- Полная форма администратора: все Markdown-поля, лимиты, языки и шаблоны,
  открытые и скрытые тесты, черновик или публикация с подтверждением.
- Обработка ошибок, загрузки и истёкшей сессии; проверка UUID и UTF-8 лимитов.

## Границы текущего API

История тренировок и результаты загружаются из backend. После старта открывается
#workspace?match=<UUID>: эту страницу можно перезагрузить или открыть снова.
Данные текущей задачи обновляются раз в пять секунд. Отображение времени учитывает
serverTime и дедлайн; обновление страницы не начинает отсчёт заново. Закрытие вкладки
не завершает тренировку. После истечения времени следующая задача ждёт нажатия кнопки.

Код и ввод сохраняются на сервере с задержкой 600 мс после изменения; у каждого
языка свой черновик. Дождитесь отметки «Черновик сохранён» перед закрытием вкладки.
Кнопки перехода и завершения сначала сохраняют текущий код. Досрочное завершение
подтверждается в окне; текущая и неоткрытые задачи получают итог Abandoned, прежние
результаты сохраняются. Последние 50 сессий доступны в истории.

Judge0 пока не исполняет принятый код: отправка остаётся Pending. Кнопка проверки
решения по тестам отключена до реализации соответствующего backend. Обычный запуск
не означает Solved. Таблица результата показывает реальные пропуски, таймауты и
незавершённые задачи, а не вымышленные успешные решения.

`/auth/me` не возвращает роли, поэтому ссылка ADMIN видна в навигации.
Сервер остаётся единственным источником прав и отвечает 403 без роли Admin.
Регистрация не выдаёт эту роль. Список языков — снимок миграции, а сервер
повторно проверяет доступность. При изменении каталога обнови `src/catalog.ts`.

## Безопасность

- Cookie остаётся Secure/HttpOnly/SameSite=Lax; frontend не читает её.
- Пароли и исходный код не записываются в localStorage/sessionStorage.
  В localStorage хранится только тема.
- В backend добавлены проверка Origin/Fetch Metadata и запрет простых формовых
  запросов к изменяющим JSON API; старый запрос logout без тела сохранён.
  Запросы CLI без Origin поддерживаются. Новых маршрутов и полей DTO нет.
- `Security__HttpsTerminatedByProxy=true` отключает перенаправление API на HTTPS
  только в Docker: TLS уже завершается на frontend. Secure-cookie не ослабляется.
- Nginx выставляет CSP, запрет iframe, nosniff и Permissions-Policy.
  Скрипты и соединения разрешены только с текущего origin; inline-стили нужны
  редактору. Markdown отправляется строкой и не вставляется в DOM как HTML.
- API-ответы не кэшируются. Сетевой таймаут — 20 секунд, автоматического повтора
  изменяющих запросов нет. После таймаута проверь состояние операции до повтора.

При проверке backend обнаружено существовавшее предупреждение NU1903 о
`Microsoft.OpenApi 2.0.0` (GHSA-v5pm-xwqc-g5wc). Зависимость backend в этой работе
не обновлялась; Swagger доступен только в Development, согласно существующей настройке.

## Разработка

Node.js 22.19+:

```powershell
npm ci
npm run dev
npm run build
npm test
```

Dev-сервер проксирует `/api` в https://localhost:8443 (запусти Docker).
Для отдельного backend создай `.env.local`:

```dotenv
VITE_API_PROXY_TARGET=https://localhost:7146
```

`secure: false` используется только dev-прокси для локального сертификата.
В Docker браузер использует HTTPS напрямую.

## Структура

- `src/App.tsx` — оболочка, авторизация, обзор, тренировки, профиль и рабочее пространство.
- `src/Admin.tsx` — создание задач.
- `src/api.ts` — типы, запросы и обработка ошибок; место для подключения будущих API.
- `src/CodeEditor.tsx` — редактор, загружается отдельным чанком.
- `src/catalog.ts` — языки, шаблоны и названия сложностей.
- `src/styles.css` — обе темы, адаптивная вёрстка и анимации.
- `nginx.conf`, `Dockerfile` — HTTPS, статические файлы и API-прокси.
