# UI/UX-проверка CodeRush — 6 ноября 2026

Проверен локальный сайт https://localhost:8443 в браузере: главная, переход к тренировкам, гостевой запуск, открытие входа и регистрации, мобильное меню, пустая форма создания задачи. Проверены мобильные экраны тренировки и создания задачи при ширине 390 px. На этих экранах горизонтального переполнения не обнаружено. В просмотренных сообщениях консоли не было ошибок и предупреждений.

## Исправления

| Приоритет | Проблема | Исправление и проверка |
| --- | --- | --- |
| P1 | Изменение полей после сохранения сбрасывало результат создания. Следующее сохранение могло создать ещё одну задачу либо отправить устаревший versionId при редактировании. | Последние id/versionId хранятся отдельно от уведомления об успешном сохранении. Сброс выполняется при явном выборе новой задачи. Проверено по коду и сборкой; серверный сценарий требует Admin. |
| P1 | Исключение sessionStorage после успешного API-запроса скрывало принятый запуск/решение; чтение хранилища также могло прервать восстановление состояния. | Доступ к хранилищу защищён: выполнение продолжает работать в памяти. Добавлены два регрессионных теста, включая SecurityError. |
| P2 | Мобильное меню не закрывалось при выборе текущей страницы: hashchange не срабатывает. | Меню закрывается при клике по ссылке. Воспроизведено до исправления и повторно проверено после обновления сборки. |
| P2 | При нескольких невалидных полях сообщение и фокус переходили к последнему полю. | Обрабатывается первое невалидное поле. До исправления пустая форма фокусировала условие, после — название задачи. Проверено в браузере. |
| P2 | Ответ автосохранения старой задачи/языка мог изменить статус текущего черновика. Ошибка оставляла надпись «Сохраняем…». | Устаревшие ответы не меняют статус; при ошибке показывается «Не удалось сохранить». Проверено по коду и сборкой. |
| P2 | Ошибка загрузки тренировки оставалась после успешного фонового восстановления. | Успешное обновление снимает сообщение об ошибке. Проверено по коду. |
| P2 | Карточки главной обещали обычный каталог и немедленный доступ к редактору, хотя каталог административный, а редактор требует тренировку. | Тексты уточняют доступ и условия запуска. Проверено в браузере после обновления. |
| P2 | При отсутствии clipboard API копирование выбрасывало синхронное исключение вместо сообщения. Кнопка могла отправить окружающую форму. | Добавлены try/catch и type="button". Проверено по коду и сборкой. |

## Валидация и ограничения

- `npm test`: 3 файла, 10 тестов прошли.
- `npm run build`: TypeScript и production-сборка прошли.
- Собранные файлы скопированы в работающий локальный контейнер frontend; UI-проверки повторены на https://localhost:8443. Docker image отдельно не пересобирался. Исходники содержат исправления для следующей сборки image.
- Полный цикл входа, сохранения задачи, тренировки и проверки решения под авторизованным пользователем не выполнялся: вкладка открыта в гостевом режиме. Эти проверки остаются необходимыми для полного E2E-покрытия.
